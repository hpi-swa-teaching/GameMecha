A GMCollisionGamePlayer is GMRotableMorph that can move and shoot, when the respective keys are pressed. It is notified upon collision with the other players projectiles, enemies and the glowing area. Its layers and mask are set by the game and it sets the projectiles layers and mask relative to its own when creating them, so that it won't collide with its own projectiles.
Both players are on layer 1, while one of them is on layer 2, the other on layer 3. Both players also are on mask 4 and 8, for collision with enemies and the glowing area. One them is also on mask 6, the other on 7 for the projectile collision.
